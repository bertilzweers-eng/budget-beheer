Cloud-synchronisatie (optioneel)

Koppel deze tool aan een eigen cloudopslag (bijv. Google Sheets via Apps Script, Firebase, of JSONBin) zodat meerdere mensen dezelfde gegevens kunnen bekijken en bewerken. Iedereen die meewerkt vult hieronder dezelfde endpoint-URL in.

Contract: deze tool doet een GET-verzoek om gegevens op te halen en een POST/PUT-verzoek (met de volledige data als JSON) om op te slaan. Elke cloudprovider die dat ondersteunt werkt, zonder dat de tool zelf aangepast hoeft te worden.

Optie A — Google Sheets (via Apps Script, gratis): Maak een nieuw Google Sheet → Extensies → Apps Script, plak onderstaande code, en implementeer als webapp (Uitvoeren als: Ik, Toegang: Iedereen): 
function doGet(e){
  var s = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('Sheet1');
  var val = s.getRange('A1').getValue() || '{}';
  return ContentService.createTextOutput(val).setMimeType(ContentService.MimeType.JSON);
}
function doPost(e){
  var s = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('Sheet1');
  s.getRange('A1').setValue(e.postData.contents);
  return ContentService.createTextOutput('{"ok":true}').setMimeType(ContentService.MimeType.JSON);
}
Gebruik de gegenereerde webapp-URL hieronder als endpoint (methode: POST).

Optie B — Firebase Realtime Database (gratis tier): gebruik als endpoint https://JOUW-PROJECT.firebaseio.com/budget.json en kies methode PUT. Geen extra headers nodig bij open regels (voor productiegebruik: beveiligingsregels instellen).

Optie C — JSONBin.io (gratis, geen code nodig): maak een bin aan op jsonbin.io, gebruik de bin-URL als endpoint (methode: PUT), en zet in "Extra headers" bijvoorbeeld: {"X-Master-Key":"jouw-sleutel","Content-Type":"application/json"}.

Let op: dit is eenvoudige synchronisatie ("laatste opslag wint"). Bij gelijktijdig bewerken door meerdere mensen kan de één de wijziging van de ander overschrijven.

⚠️ Deze sleutel/URL wordt onversleuteld opgeslagen in de browseropslag (localStorage) van dit apparaat. Gebruik dit niet op een gedeelde of publieke computer.
